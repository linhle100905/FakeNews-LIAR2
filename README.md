# Đồ án Khai phá Dữ liệu - Fake News Detection (LIAR-2)

Repository lưu trữ tài liệu và mã nguồn cho đồ án môn **Khai phá dữ liệu (Data Mining)**: Nhận diện tin giả (Fake News Detection) dựa trên tập dữ liệu **LIAR-2**.

---

## 📁 Danh mục tập tin

| Tên tập tin | Định dạng | Mô tả chi tiết |
| :--- | :---: | :--- |
| **`Fake_New_LIAR2_NoJustification.ipynb`** | Jupyter Notebook | Toàn bộ mã nguồn thực hiện thu thập/tiền xử lý dữ liệu, trích xuất đặc trưng, xây dựng mô hình học máy & đánh giá độ chính xác phân loại tin giả. |
| **`BaoCao_DoAn_FakeNews_LIAR2.docx`** | Microsoft Word | Tài liệu báo cáo hoàn chỉnh đồ án môn Khai phá Dữ liệu. |
| **`BaoCao_ThuyetTrinh_FakeNews_LIAR2_Canva_Final.pptx`** | PowerPoint | Slide thuyết trình tổng quan bài toán, phương pháp, thực nghiệm và kết luận. |

## ⚙️ Hướng dẫn chạy Notebook

1. Cài đặt Python 3.8+ và các thư viện cần thiết:
   ```bash
   pip install numpy pandas scikit-learn matplotlib seaborn nltk jupyter
   ```
2. Khởi động Jupyter Notebook hoặc Google Colab:
   ```bash
   jupyter notebook Fake_New_LIAR2_NoJustification.ipynb
   ```
3. Chạy tuần tự các cell từ trên xuống dưới để quan sát quá trình phân tích và kết quả mô hình.
